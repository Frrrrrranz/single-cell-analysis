该目录只保留必要的历史说明，不是当前 marker 提取的活动输入目录。

当前活动范围以 `db/cellxgene/our_marker_papers.xlsx` 的44条任务为准；论文 Markdown、schema v2 提取结果和复核表分别位于 `scripts/extract_markers/review_md/` 与 `scripts/extract_markers/markers_output_v2/`。

旧版全库抓取快照、legacy marker 输出、临时下载日志和非任务范围的辅助结果已清理。新的活动文件不得写入 `_archive`。
