🧬 单细胞RNA测序分析

文献复现：Peripheral Nerve Single-Cell Analysis (eNeuro, 2020) — 完整流程介绍

1. 项目背景

1.1 文献简介

本分析基于 eNeuro 2020 年发表的论文： "Peripheral Nerve Single-Cell Analysis Identifies Mesenchymal Ligands that Promote Axonal Growth"。

研究问题： 周围神经损伤后，哪些细胞类型通过分泌配体促进轴突再生？

核心发现：

  • 对小鼠坐骨神经进行单细胞RNA测序，鉴定出 7 种主要细胞类型
  • 间充质细胞（Mesenchymal cells） 是神经营养配体的最大来源（贡献了 82.5% 的配体）
  • 施万细胞（Schwann cells）是唯一的驻留神经胶质细胞，包含修复型亚群

1.2 数据来源

数据存储在 GEO: GSE147285，使用 Drop-seq 技术进行单细胞测序。

样本GEO编号文件名描述
损伤3天GSM4423506Inj_Sciatic_3d.txt.gz损伤后3天坐骨神经
新生FACSGSM4423507Neo_Sciatic_FACS.txt.gz新生鼠坐骨神经（FACS分选）
新生磁珠GSM4423508Neo_Sciatic_Beads.txt.gz新生鼠坐骨神经（磁珠去髓磷脂）
未损伤GSM4423509Uninj_Sciatic.txt.gz未损伤坐骨神经
💡 Drop-seq 是什么？ Drop-seq 是一种高通量单细胞RNA测序技术，通过微流控装置将单个细胞包裹在微滴中，每个微滴带有独特的条形码（barcode），从而实现单细胞级别的基因表达检测。数据输出格式为 DGE（Digital Gene Expression）矩阵：基因 × 细胞 的计数矩阵。

设计思路：

  • 每个样本包含：唯一名称、GEO下载链接、文件名、实验条件

  • 检查文件是否已存在，避免重复下载
🔗 GEO 数据下载原理： NCBI GEO 提供两种下载方式——① 通过 geoquery 包（R）直接读取；② 通过 HTTP 直接下载压缩文件。本分析采用后者，因为 DGE 矩阵是文本格式，直接下载后用 pandas 读取即可。

4.2 读取与合并

def load_and_merge():
    adatas = []
    for name, info in SAMPLES.items():
        filepath = os.path.join(DATA_DIR, info['filename'])
        # Drop-seq DGE 是 基因(行) × 细胞(列) 的 TSV 文件
        df = pd.read_csv(filepath, sep='\t', index_col=0, compression='gzip')
        # 转置为 细胞(行) × 基因(列)，这是 Scanpy 的标准格式
        adata = sc.AnnData(df.T)
        adata.obs['sample'] = name
        adata.obs['condition'] = info['condition']
        # 为每个细胞的 barcode 添加样本前缀，避免冲突
        adata.obs_names = [f"{name}_{bc}" for bc in adata.obs_names]
        adatas.append(adata)

    # 合并所有样本（outer join）
    adata = sc.concat(adatas, join='outer')
    # 填充 NaN 为 0
    adata.X = np.nan_to_num(adata.X, nan=0.0)
    return adata

关键原理：

  • AnnData 对象： Scanpy 的核心数据结构，包含 .X（表达矩阵）、.obs（细胞元数据）、.var（基因元数据）
  • 转置操作： Drop-seq 输出是 基因×细胞，而 Scanpy 标准格式是 细胞×基因，所以需要 .T
  • 样本前缀： 不同样本的细胞 barcode 可能重复，添加前缀确保唯一性
  • outer join： 不同样本检测到的基因集不完全一致，outer join 取并集，缺失值填 0

4.3 质控过滤

def quality_control(adata):
    # 标记线粒体基因（小鼠以 'mt-' 开头）
    adata.var['mt'] = adata.var_names.str.startswith('mt-')
    # 计算 QC 指标
    sc.pp.calculate_qc_metrics(adata, qc_vars=['mt'], ...)

    # 过滤条件：
    sc.pp.filter_cells(adata, min_genes=200)    # 至少检测到 200 个基因
    sc.pp.filter_cells(adata, max_genes=5000)   # 最多检测 5000 个基因
    adata = adata[adata.obs['pct_counts_mt'] < 10, :]  # 线粒体比例 < 10%
    sc.pp.filter_genes(adata, min_cells=3)      # 基因至少在 3 个细胞中表达

为什么这样过滤？

过滤条件去除的对象原理
min_genes=200空液滴、破碎细胞检测到的基因太少说明细胞可能已破裂或液滴为空
max_genes=5000双细胞/多细胞基因数异常高可能是一个液滴包含多个细胞
线粒体比例 < 10%受损/死亡细胞细胞膜破损时，mRNA 泄漏，线粒体基因比例相对升高
min_cells=3低表达基因在极少数细胞中表达的基因缺乏统计意义

4.4 标准化与降维

def normalize_and_reduce(adata):
    # 保存原始计数
    adata.layers['counts'] = adata.X.copy()

    # 标准化：每个细胞总 UMI 归一化到 10,000，然后取对数
    sc.pp.normalize_total(adata, target_sum=1e4)
    sc.pp.log1p(adata)

    # 高变基因选择（2,000 个）
    sc.pp.highly_variable_genes(adata, n_top_genes=2000, batch_key='sample')

    # 缩放
    sc.pp.scale(adata, max_value=10)

    # PCA 降维（30 个主成分）
    sc.pp.pca(adata, n_comps=30)

每一步的原理：

  • 归一化到 10,000： 不同细胞测序深度不同（有的细胞测得 5,000 UMI，有的 20,000），归一化消除测序深度差异
  • log1p 转换： log(x+1) 将偏态分布拉近正态分布，使低表达和高表达基因的差异更均衡
  • 高变基因选择： 2 万个基因中大部分在细胞间表达差异很小（"管家基因"），只选 2,000 个差异最大的基因用于降维，减少噪声
  • 缩放（scaling）： 将每个基因的表达值标准化为 Z-score（均值为0，方差为1），避免高表达基因主导 PCA
  • PCA： 将 2,000 维的高变基因空间压缩到 30 个主成分，保留最主要的变异信息

4.5 批次校正

def batch_correction(adata):
    try:
        import harmonypy
        sc.external.pp.harmony_integrate(
            adata, key='sample',
            basis='X_pca',
            adjusted_basis='X_pca_harmony'
        )
        use_rep = 'X_pca_harmony'
    except:
        use_rep = 'X_pca'  # Harmony 不可用时回退

为什么需要批次校正？

  • 4 个样本是在不同时间、不同条件下测序的（损伤 vs 新生 vs 未损伤）
  • 技术差异（批次效应）可能掩盖真实的生物学差异
  • Harmony 通过在 PCA 空间中迭代调整细胞位置，使不同样本的同类细胞混合在一起
  • 校正后使用 X_pca_harmony 替代 X_pca 进行后续分析

4.6 聚类与 UMAP

def cluster_and_visualize(adata, use_rep):
    # 构建邻域图（kNN 图）
    sc.pp.neighbors(adata, n_pcs=20, use_rep=use_rep)

    # UMAP 降维（用于可视化）
    sc.tl.umap(adata)

    # Leiden 聚类
    sc.tl.leiden(adata, resolution=0.8)

核心原理：

  • kNN 图： 每个细胞找到 20 个最近的邻居细胞（基于 PCA 空间的欧氏距离），构建细胞间的连接图
  • Leiden 聚类： 在图结构上应用社区发现算法，将连接紧密的细胞分为同一聚类。resolution=0.8 控制聚类粒度——值越大聚类越多
  • UMAP： 一种流形学习降维方法，在 2D 平面上尽可能保持细胞间的全局和局部距离关系，比 t-SNE 更快、全局结构保留更好

    'B cells': ['Cd19', 'Cd79a', 'Ms4a1'],
    'Mast cells': ['Cpa3', 'Kit', 'Fcer1a'],
}

# 注释方法：计算每个聚类中各标志基因的平均表达，取最高分
for cluster in adata.obs['leiden'].cat.categories:
    for cell_type, genes in available_markers.items():
        score = mean(该聚类中这些基因的表达)
        if score > best_score:
            best_score = score
            best_type = cell_type
    cluster_annotations[cluster] = best_type

注释策略：

  • 标志基因（Marker Genes）： 每种细胞类型都有特异性高表达的基因，来自文献报道
  • 自动注释： 对每个聚类，计算所有标志基因组的平均表达，得分最高的细胞类型即为该聚类的注释
  • 验证手段：
    • 点图（Dotplot）—— 同时查看多个标志基因在多个聚类中的表达模式
    • UMAP 表达图 —— 查看单个基因在 UMAP 上的分布
    • 小提琴图 —— 查看标志基因在不同细胞类型中的表达分布
