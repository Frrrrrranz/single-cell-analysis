🧬 单细胞RNA测序分析

eNeuro, 2020 — Peripheral Nerve Single-Cell Analysis

1. 项目背景

1.1 文献简介

本分析基于 eNeuro 2020 年发表的论文： "Peripheral Nerve Single-Cell Analysis Identifies Mesenchymal Ligands that Promote Axonal Growth"。

研究问题： 周围神经损伤后，哪些细胞类型通过分泌配体促进轴突再生？

核心发现：

  • 对小鼠坐骨神经进行单细胞RNA测序，鉴定出 7 种主要细胞类型
  • 间充质细胞（Mesenchymal cells） 是神经营养配体的最大来源（贡献了 82.5% 的配体）
  • 施万细胞（Schwann cells）是唯一的驻留神经胶质细胞，包含修复型亚群

1.2 数据来源

数据存储在 GEO: GSE147285，使用 Drop-seq 技术进行单细胞测序。

样本GEO编号文件名描述

💡 Drop-seq 是什么？ Drop-seq 是一种高通量单细胞RNA测序技术，通过微流控装置将单个细胞包裹在微滴中，每个微滴带有独特的条形码（barcode），从而实现单细胞级别的基因表达检测。数据输出格式为 DGE（Digital Gene Expression）矩阵：基因 × 细胞 的计数矩阵。

4.2 读取与合并

def load_and_merge():
    adatas = []
    for name, info in SAMPLES.items():
        df = pd.read_csv(filepath, sep='\t', index_col=0, compression='gzip')
        adata = sc.AnnData(df.T)
        adata.obs['sample'] = name
        adata.obs_names = [f"{name}_{bc}" for bc in adata.obs_names]
        adatas.append(adata)

    adata = sc.concat(adatas, join='outer')
    adata.X = np.nan_to_num(adata.X, nan=0.0)
    return adata

关键原理：

  • AnnData 对象： Scanpy 的核心数据结构
  • 转置操作： Drop-seq 输出是 基因×细胞，Scanpy 标准格式是 细胞×基因
  • 样本前缀： 不同样本的细胞 barcode 可能重复，添加前缀确保唯一性
  • outer join： 不同样本检测到的基因集取并集，缺失值填 0

4.3 质控过滤

def quality_control(adata):
    adata.var['mt'] = adata.var_names.str.startswith('mt-')
    sc.pp.calculate_qc_metrics(adata, qc_vars=['mt'], ...)

    sc.pp.filter_cells(adata, min_genes=200)    # 至少检测到 200 个基因
    sc.pp.filter_cells(adata, max_genes=5000)   # 最多检测 5000 个基因
    adata = adata[adata.obs['pct_counts_mt'] < 10, :]  # 线粒体比例 < 10%
    sc.pp.filter_genes(adata, min_cells=3)      # 基因至少在 3 个细胞中表达
过滤条件去除的对象原理
min_genes=200空液滴、破碎细胞检测到的基因太少说明细胞可能已破裂或液滴为空
max_genes=5000双细胞/多细胞基因数异常高可能是一个液滴包含多个细胞
线粒体比例 < 10%受损/死亡细胞细胞膜破损时，mRNA 泄漏，线粒体基因比例相对升高
min_cells=3低表达基因在极少数细胞中表达的基因缺乏统计意义

4.3b 双细胞检测

def detect_doublets(adata):
    for sample_name in adata.obs['sample'].cat.categories:
        sample_adata = adata[mask].copy()
        sc.pp.scrublet(sample_adata, random_state=42)
        if 'predicted_doublet' in sample_adata.obs:
            doublet_labels[mask] = sample_adata.obs['predicted_doublet']

    adata = adata[~adata.obs['doublet'].values, :].copy()

为什么需要双细胞检测？

  • 在液滴包裹阶段，有时两个或多个细胞被包裹进同一个液滴，形成"双细胞"
  • 双细胞在聚类时会形成虚假的"中间过渡态"，干扰后续的生物学解释
  • Scrublet 通过模拟人工双细胞，比较真实细胞与模拟双细胞的近邻密度分布，为每个细胞计算双细胞得分

4.5 批次校正

def batch_correction(adata):
    try:
        import harmonypy
        sc.external.pp.harmony_integrate(
            adata, key='sample',
            basis='X_pca',
            adjusted_basis='X_pca_harmony'
        )
        use_rep = 'X_pca_harmony'
    except:
        use_rep = 'X_pca'

4 个样本是在不同时间、不同条件下测序的，Harmony 在 PCA 空间中迭代调整细胞位置，消除批次效应。

  • 验证文献中报道的标志基因是否确实是各聚类的最优特征
  • 定义了 14 个间充质细胞配体基因列表，验证间充质细胞是否是这些配体的主要来源

# 注释方法：计算每个聚类中各标志基因的平均表达，取最高分
for cluster in adata.obs['leiden'].cat.categories:
    for cell_type, genes in available_markers.items():
        score = mean(该聚类中这些基因的表达)
        if score > best_score:
            best_score = score
            best_type = cell_type
    cluster_annotations[cluster] = best_type

注释策略：

  • 标志基因： 每种细胞类型都有特异性高表达的基因，来自文献报道
  • 自动注释： 对每个聚类，计算所有标志基因组的平均表达，得分最高的即为该聚类的注释
