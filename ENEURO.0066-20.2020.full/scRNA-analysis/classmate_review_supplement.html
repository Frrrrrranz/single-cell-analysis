校正声明 · 关于 LIGAND_GENES 的判读错误

你指出得对。重新审视同学的 PDF 后，LIGAND_GENES 那段代码并不是配体-受体分析，而是细胞类型注释完成后的验证步骤——目的是看间充质细胞 cluster 是否真的能高表达这些特征基因，作为对注释结果的旁证。

代码原文注释："# 检查配体基因在间充质细胞中的表达" —— 实际是把 ECM 标志基因列入了 LIGAND_GENES 变量名下，变量命名误导，但功能上属于细胞类型 marker 验证。

真正的问题变成了两个：（1）变量命名错误——把 Col1a1/Fn1/Sparc 这些 ECM 蛋白叫成 "LIGAND_GENES" 容易误导后续读代码的人；（2）同学的分析确实只做到细胞类型注释，没有进入论文真正的核心（配体-受体互作预测），后者需要补做。

所以前次评审中"把 ECM 当成配体"的指控不成立，评分上调。但"分析深度未到论文核心"仍然成立。

📊 选型决策树（给同学的具体建议）

场景 1：想最快出结果，不切换语言生态
→ 用 LIANA+（Python，原生 AnnData，多方法集成）

场景 2：想做最完整的分析，包括信号通路级别 + 多条件对比
→ 切换到 CellChat v2（R）。需要先把 AnnData 导出为 Seurat 对象或表达矩阵 + 元数据 + barcode

场景 3：想了解配体作用的下游分子机制（比如 Angpt1 通过 TEK 受体激活了什么通路）
→ 用 NicheNet（R）

场景 4：未来要做空间转录组扩展
→ 用 Squidpy（Python）

🛠️ 给本论文场景的具体推荐流程

推荐组合：LIANA+ 主分析 + NicheNet 补充下游靶基因

① 用 LIANA+ 对损伤神经数据集计算所有 cluster 间的配体-受体互作；
② 重点提取 Mesenchymal/endoneurial → Schwann 的互作排名；
③ 同时提取 Mesenchymal → 神经元的互作（神经元数据需另外引入）；
④ 对前 10 名配体-受体对，用 NicheNet 推断下游靶基因；
⑤ 验证论文鉴定的 ANGPT1、CCL11、VEGFC 是否在前列。

⚠️ 关键提醒： 论文做的是神经组织 → 外周神经元的互作预测，神经元（DRG/SCG/MN/RGC）的受体数据来自 microarray 和 bulk RNA-seq，不在同一 scRNA-seq 数据集里。

如果同学要严格复现这个跨数据类型的分析，需要：
① 下载论文用的神经元 microarray 数据（GSE146958）；
② 把受体表达从 microarray 提取出来作为 "external" 细胞类型；
③ 在 LIANA+ 中可用 external_resource 参数引入外源数据。

或者简化为：只做 scRNA-seq 内部的细胞间互作（如 Mesenchymal → Schwann），不涉及外部神经元 — 这也能验证"间充质是配体源"的核心结论。
