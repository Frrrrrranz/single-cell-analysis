# 文章报告
在哺乳动物生物学中，外周神经系统（PNS）展现出了令人瞩目的再生能力，这与中枢神经系统（CNS）在损伤后普遍存在的抑制性环境形成了鲜明对比 。这种再生潜力的核心在于外周神经能够为发育中和再生中的轴突提供一个高度支持性的生长环境 。长期以来，学术界普遍认为这种支持能力主要归功于神经驻留的施万细胞（Schwann cells）分泌的旁分泌因子，施万细胞在神经受损后会重编程为一种特殊的“修复”表型，指导轴突跨越损伤区域 。然而，随着单细胞转录组测序（scRNA-seq）和高分辨率质谱技术的发展，研究人员开始意识到，外周神经实际上是一个结构极其复杂的组织，包含血管相关细胞、免疫细胞以及具有多种起源的间充质细胞 。特别是最近的研究表明，间充质细胞在构建神经旁分泌环境方面发挥了此前被严重低估的作用 。

## 外周神经组织的细胞类型组成与鉴定
为了全面解析外周神经在稳态、发育及损伤条件下的分子景观，研究者针对啮齿动物（大鼠和小鼠）的坐骨神经进行了深入的细胞分选与单细胞测序分析  1 。坐骨神经是一个混合神经，包含了来自感觉神经元、交感神经元和运动神经元的轴突  2 。

### 受损坐骨神经中的细胞聚类分析
在针对损伤后3天（3 DPI）和9天（9 DPI）的远端坐骨神经段进行的研究中，通过高通量液滴单细胞RNA测序（Drop-seq）技术，研究人员成功鉴定出了多种截然不同的细胞群落 。这些细胞类型通过已知的标志基因（Marker genes）表达谱进行定义，并利用计算管道进行可视化 。
在损伤组织中测出的主要细胞类型包括：

| 细胞大类 | 具体细胞类型 | 关键标志基因 (Marker Genes) | 备注 |
| --- | --- | --- | --- |
| 神经谱系细胞 | 施万细胞 (Schwann Cells) | Sox10, Ngfr (p75NTR), S100b | 神经主要的驻留神经胶质细胞 |
| 间充质谱系 | 神经内膜间充质细胞 | Pdgfra, Etv1, Wif1, Sox9 | 与轴突和施万细胞紧密贴合 |
|  | 神经外膜间充质细胞 | Pdgfra, Pcolce2, Dpp4, Dpt, Ly6c1 | 位于神经最外层的结缔组织 |
|  | 神经束膜间充质细胞 | Pdgfra, Slc2a1, Casq2, Msln | 包绕神经纤维束 |
|  | 神经桥分化细胞 | Pdgfra, Dlk1, Mest | 在神经断端间形成桥梁的细胞 |
| 血管相关细胞 | 内皮细胞 (Endothelial) | Pecam1 (Cd31), Plvap, Esam | 构成血-神经屏障 |
|  | 平滑肌细胞/周细胞 | Desmin, Mylk, Acta2, Rgs5 | 血管收缩与支撑细胞 |
| 免疫细胞 | 巨噬细胞 | Aif1 (Iba1), Cd68 | 负责清除髓磷脂碎片 |
|  | 淋巴细胞 (T细胞/NK细胞) | Ptprcap, Trbc2, Cd52 | 损伤后的免疫监测 |
|  | B细胞 | Cd19 | 主要在损伤后9天显著增加 |
|  | 肥大细胞 (Mast Cells) | Cpa3 | 参与早期炎症反应 |

单细胞分析显示，损伤后3天和9天的远端神经在细胞组成上高度相似，细胞群在大多数聚类中相互交织，这表明损伤后诱导的微环境在最初几天内即趋于稳定 。唯一显著的时间点差异在于B细胞的比例，这类细胞在9 DPI时几乎排他性地出现 。

### 未损伤与发育中神经的细胞景观
为了对比损伤引起的改变，研究者同样对成年未损伤神经和新生儿（P2-P4）发育中的神经进行了测序 。
在未损伤的成年坐骨神经中，可以清晰地分选出髓磷脂化施万细胞（表达 *Mbp, Pmp22, Plp1*）和非髓磷脂化施万细胞（表达 *Cdh2, L1cam*） 。间充质细胞群在稳态下同样存在，表现为神经外膜、束膜和内膜的不同亚群 。值得注意的是，未损伤神经中几乎检测不到增殖细胞（*Top2a, Mki67* 阴性），且免疫细胞比例极低（仅占约1.9%） 。
在新生儿发育中的神经中，细胞群表现出更强的增殖特征。施万细胞谱系被细分为五个聚类，其中包括正在增殖的施万细胞和初期的髓磷脂化施万细胞 。这种发育状态的转录组特征在神经受损后会在“修复型”施万细胞中部分重现 。

## 神经谱系细胞的深度解析
在上述外周组织测得的细胞类型中，能够被归类为“神经细胞”或“神经相关细胞”的类型主要分为两大范畴：组织驻留细胞和作为通讯目标的外部神经元 。

### 施万细胞：核心驻留神经细胞
在外周坐骨神经组织内部，施万细胞是唯一的驻留神经胶质细胞类型，也是该项单细胞研究中直接测得的、数量最庞大的神经谱系细胞 。它们起源于神经嵴，根据功能状态可分为：

1. **髓磷脂化施万细胞**：负责包裹大直径轴突，形成髓磷脂鞘 。
2. **非髓磷脂化施万细胞**：包裹小直径轴突（如Remak束） 。
3. **修复型施万细胞**：这是在神经受损后由髓磷脂化和非髓磷脂化施万细胞去分化而来的特殊表型 。它们不再维持髓磷脂，而是转而分泌大量的神经营养因子，如 *Gdnf, Bdnf, Artn*，并启动自噬过程以清理变性的轴突碎片 。

### 神经元：外部通讯目标
必须明确的是，在该项单细胞RNA测序中，**神经元（Neurons）的胞体并不包含在外周神经组织测出的细胞聚类中**。外周神经（坐骨神经）仅含有神经元的轴突，而由于轴突缺乏细胞核且其mRNA总量远低于胞体，标准的液滴单细胞测序技术主要捕获的是驻留在神经鞘内的有核细胞 。
然而，研究者为了完整构建细胞间通讯模型，通过外部实验手段引入了以下神经元的数据：

- **感觉神经元**：从胚胎（E15）大鼠背根神经节（DRG）中分离培养，并进行了转录组和蛋白质组分析 。
- **交感神经元**：从新生大鼠上颈神经节（SCG）中分离，作为通讯目标进行建模 。
- **运动神经元**：利用已发表的成年小鼠腰部运动神经元微阵列数据 。
- **视网膜神经节细胞（RGCs）**：作为中枢神经系统（CNS）神经元的代表，研究其对坐骨神经旁分泌信号的潜在反应 。
因此，虽然神经元本身不是坐骨神经测序产出的“细胞聚类”，但它们是该研究中旁分泌作用的“目标受体细胞”，在逻辑上被整合进了神经通讯网络中 。

### 卫星胶质细胞的说明
在某些外周神经系统的单细胞图谱中，如果样本取自神经节（如DRG），会检测到大量包裹神经元胞体的卫星胶质细胞（SGCs） 。但在本文所讨论的坐骨神经干（Nerve Trunk）的测序结果中，并未明确列出卫星胶质细胞聚类，这与其解剖学分布（主要位于神经节）相一致 。

## 细胞间通讯分析的计算工具与方法
为了从复杂的单细胞转录组数据中提取具有生物学意义的通讯网络，研究团队采用了一套结合了自定义脚本、已知数据库和蛋白质组学验证的综合方法 。

### 核心计算工具与流程

1. **Drop-seq 数据处理管道**：采用由 Innes 和 Bader (2019) 描述的计算流程 。该管道包括低质量细胞过滤（基于UMI计数和线粒体基因比例）、双细胞移除以及对极低检测基因的剔除 。
2. **标准化与降维**：使用 R 语言中的 `scran` 包进行转录组标准化，纠正测序深度的差异 。随后利用 `Seurat` 软件包执行主成分分析（PCA）和 t-SNE 可视化，并使用基于共享最近邻（SNN）模块化优化的聚类算法进行细胞分类 。
3. **Harmony 批次校正**：在合并来自不同实验（如 FACS 分选、髓磷脂清除珠处理）和不同时间点的数据集时，应用了 **Harmony** 方法来消除技术偏倚，确保细胞是按生物学类型而非实验批次聚类的 。
4. **"Cellcellinteractnet" 自定义 Python 脚本**：这是本研究中识别配体-受体相互作用的核心计算工具 。该脚本由 Python 2.7.6 编写，其逻辑是读取神经细胞分泌的 143 种受损神经相关配体，并将其与神经元表达的受体数据库进行匹配 。
5. **Cytoscape 3.7.0**：用于对预测出的单向旁分泌交互网络进行图形化建模和可视化 。

### 配体-受体数据库的构建
研究者并未使用现成的商业通讯数据库，而是基于 Yuzwa 等人（2016）的工作构建了一个**高度手动管理的配体-受体数据库**。该数据库经过特别优化，排除了那些仅具有结构功能而缺乏明确受体介导信号传导作用的细胞外基质蛋白（ECM） 。配体基因的筛选门槛设定为表达量不低于 *Ntf3*（神经营养因子3）mRNA 的水平，这确保了所选配体在神经微环境中具有潜在的生物学丰度 。

### 蛋白质组学辅助验证（Cell-surface Capture Mass Spectrometry）
为了提高通讯分析的准确性，研究者引入了细胞表面捕获质谱技术 。

- **原理**：利用高碘酸钠氧化神经元表面的糖蛋白，通过肼树脂捕获这些蛋白，随后进行胰蛋白酶消化，并在 Orbitrap Q-Exactive 质谱仪上进行鉴定 。
- **价值**：这一步骤对于确定“受体”的存在至关重要。仅仅依靠神经元的 RNA 数据无法确认蛋白质是否真的易位到了细胞膜表面。通过这种方式，研究者在感觉神经元上鉴定出了 608 种蛋白，在交感神经元上鉴定出了 271 种蛋白，为计算模型提供了坚实的蛋白水平证据 。

## 神经细胞相关的细胞间通讯网络
该研究最重大的贡献之一是重新定义了神经再生的旁分泌版图，揭示了间充质细胞在支持神经细胞（尤其是轴突）生长方面的核心地位 。

### 坐骨神经配体环境的整体景观
通过对 3 DPI 和 9 DPI 组合数据集的分析，研究者锁定了 143 种在受损神经中表达的配体 mRNA 。下表展示了这些配体在不同细胞类型中的来源分布：

| 细胞来源 | 表达配体数量 (143种中) | 最高表达配体数量 | 典型神经支持因子 |
| --- | --- | --- | --- |
| 组合间充质细胞 | 118 (82.5%) | 71 | Angpt1, Ccl11, Fgf7, Hgf, Il33, Wnt5a |
| 施万细胞 | 74 (51.7%) | 23 | Gdnf, Bdnf, Artn, Dhh, Ucn2, Clcf1 |
| 血管内皮细胞 | - | 18 | Bmp4, Pdgfb, Vegfc |
| 周细胞/平滑肌 | - | 15 | Ngf, Bmp2 |
| 免疫细胞 | - | 16 | Osm, Tnf |

### 间充质细胞对神经元的关键通讯
分析表明，**超过一半的预测配体是由神经驻留间充质细胞产生的**，而非施万细胞 。特别是位于神经内膜、与轴突物理距离最近的间充质细胞，其在损伤后表现出了强烈的配体上调反应 。
计算模型预测并验证了以下关键的通讯通路：

- **ANGPT1-TEK (Tie2)**：间充质细胞产生的血管生成素1（ANGPT1）与神经元表面的 TEK 受体相互作用 。实验证明，局部应用 ANGPT1 可显著增强交感轴突的生长密度 。
- **CCL11-CXCR3**：趋化因子 CCL11（Eotaxin）主要由神经内膜间充质细胞产生，能够促进轴突生长，这颠覆了其以往在 CNS 中作为老化因子的负面形象 。
- **VEGFC-FLT4/NRP1**：血管内皮生长因子 C（VEGFC）虽然在间充质中表达水平较低，但其受体在感觉和交感神经元表面均有稳定表达，其促轴突生长作用已在体外得到证实 。

### 施万细胞的特异性支持作用
虽然间充质细胞提供了广泛的信号背景，但施万细胞在提供“强力”和“传统”的再生信号方面不可或缺 。施万细胞是 *Gdnf*（胶质细胞源性神经营养因子）、*Artn*（阿特明蛋白）和 *Bdnf*（脑源性神经营养因子）的主要来源 。
一个有趣的发现是，受损后的“修复型施万细胞”在转录谱上与新生儿发育中的施万细胞更为相似（相关系数 $r=0.88$），而与成年稳态下的非髓磷脂化施万细胞差异较大（$r=0.76$） 。这表明神经损伤诱导了一场向发育状态的“分子回归”，旨在重新激活支持轴突生长的发育程序 。

### 跨系统的普适性：对 CNS 神经元的通讯
研究者通过将模型扩展到运动神经元和 CNS 的视网膜神经节细胞（RGCs），得出了一个深远的结论：外周神经提供的生长环境具有惊人的**普适性**。

- 在预测的 122 种交感/感觉神经元交互中，有 121 种同样适用于运动神经元 。
- 对于 RGCs，所有 122 种外周神经通讯路径均被预测为有效，且 RGCs 还具有额外的趋化因子交互能力 。
这一结果为临床上使用外周神经移植物（Peripheral Nerve Grafts）来诱导脊髓或视神经等 CNS 轴突再生的成功提供了分子基础。外周神经并不是为特定类型的神经元定制信号，而是产生了一套能够被绝大多数神经元受体库感知的“通用生长配方” 。

## 核心洞察与未来展望
通过整合单细胞转录组学、细胞表面蛋白质组学和系统生物学建模，本研究彻底改变了我们对外周神经修复微环境的认知 。

### 冗余性与稳健性
神经通讯网络展现出了极高的冗余性 。例如，施万细胞分泌的 *Clcf1, Crlf1* 和间充质细胞分泌的 *Lif* 均作用于神经元表面的 gp130（*Il6st*）和 *Lifr* 受体复合物 。这种多来源、多因子的信号重叠确保了即使某一类细胞受损或某一基因失活，再生的核心旁分泌支持也不会完全崩溃 。

### 临床干预的新靶点
传统神经再生疗法过度依赖于施万细胞或单一因子（如 NGF）的输送 。然而，本报告的数据表明，未来的治疗策略应当考虑：

1. **激活内源性间充质细胞**：利用 ANGPT1, CCL11 和 VEGFC 等因子的协同作用 。
2. **模拟全细胞微环境**：开发包含多种谱系信号的生物材料支架，而不仅仅是单一的神经营养因子包埋 。
总之，外周神经的再生优势源于施万细胞与间充质细胞之间精密而复杂的协作，这种协作通过一种通用的配体-受体逻辑，为跨越 PNS 和 CNS 界限的轴突再生提供了可能 。未来的研究应进一步探索这些间充质来源因子在活体模型中的长期效应，及其在人类神经修复中的转化潜力。
