补充材料：神经元数据引入方法详解

文献：Peripheral Nerve Single-Cell Analysis Identifies Mesenchymal Ligands that Promote Axonal Growth (eNeuro, 2020)

对应主报告：PNS旁分泌配体-受体网络.html

本材料目的：详细展开"坐骨神经测序中引入神经元数据"的方法学细节

核心问题：坐骨神经中只有轴突（无细胞核），标准Drop-seq无法捕获神经元胞体

解决策略：通过独立实验"外部引入"四种神经元的转录组和蛋白质组数据

1. 为什么需要引入神经元数据？

1.1 坐骨神经的解剖学限制

  • 坐骨神经是混合神经，包含来自感觉神经元（DRG）、交感神经元（SCG）和运动神经元（脊髓）的轴突
  • 但神经元胞体位于背根神经节（DRG）、上颈神经节（SCG）和脊髓中，不在坐骨神经组织内
  • 坐骨神经中只有轴突——轴突缺乏细胞核，mRNA总量极低

1.2 Drop-seq 技术的偏向性捕获

  • 标准Drop-seq（高通量液滴单细胞RNA测序）依赖细胞核（或完整细胞）来捕获转录组
  • 因此只能捕获驻留在神经鞘内的有核细胞：施万细胞、间充质细胞、免疫细胞、血管相关细胞
  • 神经元胞体不在坐骨神经中 → 测序结果中没有神经元聚类
核心逻辑：要构建"坐骨神经细胞→神经元"的配体-受体通讯模型，必须知道神经元表达哪些受体。但坐骨神经测序测不到神经元胞体，因此需要通过独立实验外部引入神经元数据。
论文原文（Page 19/Results）：
"To ask which nerve cells express these ligands, we performed single-cell RNA sequencing (scRNA-seq), initially analyzing the distal sciatic nerve 3 d following a nerve transection."
—— 坐骨神经测序只针对神经组织本身，不包含神经元胞体。

Figure 1: 坐骨神经单细胞测序的细胞聚类（无神经元）

损伤后3天坐骨神经的t-SNE聚类图（论文Figure 1C/E）
  • 图C：3 DPI坐骨神经t-SNE聚类，共鉴定出9个细胞簇
  • 图E：合并3+9 DPI数据的t-SNE聚类，共12个细胞簇
  • 关键观察：所有聚类均为有核细胞——施万细胞、间充质细胞、内皮细胞、免疫细胞等
  • 无神经元聚类：神经元胞体不在坐骨神经中，因此t-SNE图上没有神经元群体
→ 结论：坐骨神经Drop-seq只能捕获驻留的有核细胞。要获得神经元受体数据，必须通过独立实验外部引入。

2. 四种神经元数据来源总览

本研究共引入四种神经元作为配体-受体通讯的靶细胞，但数据来源和方法各不相同：

神经元类型 数据来源 转录组方法 蛋白质组方法 验证层级
感觉神经元（DRG） 自行培养（E15大鼠DRG） 微阵列芯片（n=6） CSC-MS（608种蛋白） ✅ 双重验证
交感神经元（SCG） 自行培养（新生大鼠SCG） 微阵列芯片（n=4） CSC-MS（271种蛋白） ✅ 双重验证
运动神经元 公共数据库（Kaplan et al., 2014） 微阵列芯片（已发表） 无 ⚠️ 仅转录组
RGCs（视网膜神经节细胞） 公共数据库（Blanco-Suarez et al., 2018） RNA-seq（已发表） 无 ⚠️ 仅转录组
关键差异：感觉神经元和交感神经元是自行培养 + 双重验证（转录组+蛋白质组），可靠性最高。运动神经元和RGCs引用已发表公共数据，仅有转录组数据，可靠性较低。

3. 方法一：感觉神经元（DRG）—— 最完整的双重验证

3.1 实验流程

E15大鼠DRG分离 → 培养9天 → CA纯化（除杂细胞） → 微阵列芯片（n=6） → CSC-MS质谱（608种蛋白）

3.2 详细说明

  • 来源：胚胎第15天（E15）大鼠背根神经节（DRG）
  • 培养：分离后培养9天，使神经元成熟并建立稳定的转录组状态
  • 纯化：使用CA（胞嘧啶阿拉伯糖苷，Cytosine Arabinoside）处理——CA是一种DNA合成抑制剂，能选择性杀死培养物中分裂的非神经元细胞（如成纤维细胞、施万细胞），从而纯化神经元群体
  • 转录组：6个独立生物学重复，使用Affymetrix GeneChip Rat Gene 2.0 ST Arrays进行微阵列分析
  • 蛋白质组：细胞表面捕获质谱（CSC-MS），鉴定出608种表面蛋白
论文原文（Page 36/Results）：
"We therefore complemented the proteomics by analyzing six...independent biological replicates of cultured DRG...RNA, respectively, on Affymetrix GeneChip Rat Gene 2.0 ST Arrays."
"Cell-surface proteomics...identified 608 and 271 unique proteins on sensory and sympathetic neurons, respectively."

4. 方法二：交感神经元（SCG）—— 同样完整的双重验证

4.1 实验流程

新生（P1-P2）大鼠SCG分离 → 培养6天 → CA纯化（除杂细胞） → 微阵列芯片（n=4） → CSC-MS质谱（271种蛋白）

4.2 详细说明

  • 来源：新生（P1-P2，出生后1-2天）大鼠上颈神经节（SCG）
  • 培养：分离后培养6天
  • 纯化：同样使用CA（胞嘧啶阿拉伯糖苷）处理，消除分裂的非神经元细胞
  • 转录组：4个独立生物学重复，使用Affymetrix GeneChip Rat Gene 2.0 ST Arrays
  • 蛋白质组：CSC-MS鉴定出271种表面蛋白（感觉/交感交集219种）
  • 数量差异原因：交感神经元样本蛋白浓度较低（平均~300 μg/ml vs 感觉神经元~1100 μg/ml），导致鉴定到的蛋白数量较少
论文原文（Page 36/Results）：
"The lower number of unique proteins on sympathetic neurons is likely due to decreased protein that was isolated (samples averaged ~1100 vs 300 mg/ml for sensory vs sympathetic neurons)."

5. 方法三：运动神经元—— 引用公共数据库

5.1 数据来源

  • 原始文献：Kaplan et al., 2014, Neuron
  • 标题："Neuronal Matrix Metalloproteinase-9 Is a Determinant of Selective Neurodegeneration"
  • 数据平台：微阵列芯片（Affymetrix）
  • 样本：显微切割的P7（出生后7天）小鼠腰髓运动神经元
  • GEO编号：GSE52118

5.2 数据分析方法

  • 使用与感觉/交感神经元相同的阈值标准（前87%的mRNA）定义受体
  • 鉴定出322种受体mRNA
  • 其中272种与感觉/交感神经元重叠

5.3 局限性

  • 仅转录组数据——无蛋白质组验证
  • 小鼠数据（其他三种为大鼠数据）——跨物种比较
  • 无法确认受体蛋白是否真实存在于细胞膜表面
论文原文（Page 60/Results）：
"For motor neurons, we analyzed previously published microarray data from microdissected P7 mouse lumbar motor neurons (Kaplan et al., 2014), identifying receptor mRNAs using the same thresholding cutoff as for the sensory neurons (top 87% of mRNAs)."

6. 方法四：视网膜神经节细胞（RGCs）—— 引用公共数据库

6.1 数据来源

  • 原始文献：Blanco-Suarez et al., 2018
  • 数据平台：RNA-seq（而非微阵列芯片）
  • 样本：P5-P7大鼠RGCs
  • GEO编号：GSE108484
  • 作为CNS代表：RGCs是中枢神经系统（CNS）神经元，正常情况下在CNS中不能再生，但能在移植的外周神经中再生

6.2 数据分析方法

  • 使用FPKM ≥ 1作为表达阈值
  • 鉴定出320种受体mRNA
  • 其中258种与所有其他三种神经元重叠

6.3 特殊意义

  • RGCs作为CNS神经元的代表，用于验证"外周神经的通用生长配方"假说
  • 结果：所有122种外周神经通讯路径均被预测对RGCs有效
  • 为外周神经移植物用于视神经再生提供了分子基础
论文原文（Page 60/Results）：
"We obtained similar findings when we analyzed RGCs using a bulk RNA-seq dataset generated from P5-P7 rat RGCs (Blanco-Suarez et al., 2018)."

7. 核心技术详解：CSC-MS（细胞表面捕获质谱）

7.1 为什么需要蛋白质组验证？

  • 仅靠RNA数据不能证明受体蛋白已易位到细胞膜表面
  • mRNA表达 ≠ 蛋白表达 ≠ 蛋白正确定位到细胞膜
  • 只有通过质谱在膜表面真实检测到蛋白，才能确认通讯链路的物理存在

7.2 CSC-MS 实验原理（四步法）

① 化学氧化 → ② 亲和捕获 → ③ 酶切 → ④ 质谱鉴定
步骤操作原理
① 氧化 高碘酸钠（NaIO₄, 5 mM）处理活神经元 特异性氧化细胞表面糖蛋白的糖链上的邻位二醇基团，生成醛基（-CHO）
② 捕获 细胞裂解液与肼树脂（Hydrazide Resin）孵育 醛基与肼基团（-NH-NH₂）形成稳定的腙键（C=N-NH-）共价连接，特异性富集表面糖蛋白
③ 酶切 DTT还原 → 碘乙酰胺烷基化 → 胰蛋白酶（Trypsin）酶切 → PNGaseF去N-糖链 将捕获的蛋白水解为肽段，去除糖链便于质谱分析
④ 鉴定 Orbitrap Q-Exactive质谱仪高分辨率鉴定 通过肽段质量指纹图谱鉴定蛋白身份
论文原文（Page 36/Results）：
"PANTHER classification identified most of these proteins as receptors, transporters and hydrolases, indicating appropriate enrichment for cell-surface proteins."

Figure 5B: CSC-MS 鉴定到的表面受体蛋白分类

CSC-MS鉴定到的表面受体蛋白分类柱状图（论文Figure 5B）
  • 柱状图展示：感觉神经元（DRG）和交感神经元（SCG）表面鉴定到的受体蛋白类型
  • 受体类型包括：GPCR（G蛋白偶联受体）、RTK（受体酪氨酸激酶）、细胞因子受体、配体门控离子通道、受体磷酸酶等
  • PANTHER分类：大部分鉴定到的蛋白为受体、转运蛋白和水解酶，确认了表面蛋白的有效富集

8. 验证层级对比与可靠性评估

8.1 四种神经元的数据可靠性对比

神经元类型 数据来源 转录组 蛋白质组 物种 可靠性
感觉神经元（DRG） 自行培养 ✅ 微阵列（n=6） ✅ CSC-MS（608种） 大鼠 最高
交感神经元（SCG） 自行培养 ✅ 微阵列（n=4） ✅ CSC-MS（271种） 大鼠 最高
运动神经元 公共数据库 ✅ 微阵列 ❌ 无 小鼠 中等
RGCs 公共数据库 ✅ RNA-seq ❌ 无 大鼠 中等

8.2 对研究结论的影响

  • 感觉/交感神经元的通讯预测有蛋白质组学支撑，可靠性最高
  • 运动神经元和RGCs的通讯预测仅基于转录组数据，存在假阳性风险
  • 但论文指出（Page 36/Results）："Cell-surface proteomics is relatively insensitive, and it has previously been shown that more sensitive transcriptomic profiling can also be used to identify biologically relevant paracrine interactions"——即转录组数据虽然灵敏度更高，但特异性较低
  • 因此，论文对感觉/交感神经元的结论最为可靠，对运动神经元和RGCs的结论需要谨慎解读
论文原文（Page 36/Results）：
"Cell-surface proteomics is relatively insensitive, and it has previously been shown that more sensitive transcriptomic profiling can also be used to identify biologically relevant paracrine interactions (Johnston et al., 2016; Yuzwa et al., 2016; Voronova et al., 2017)."
