慢性压迫损伤后大鼠坐骨神经
单细胞转录组图谱与细胞间通讯分析

scRNA-seq generates a molecular map of emerging cell subtypes after sciatic nerve injury in rats

Communications Biology, 2022

Lovatt et al., 2022, Commun. Biol. 5, 1105

关键词：单细胞RNA测序 · 慢性压迫损伤（CCI） · 施万细胞 · 配体-受体相互作用 · 神经病理性疼痛

1. 研究背景

外周神经损伤与神经病理性疼痛

  • 慢性神经病理性疼痛影响全球 7-10% 的人口，现有药物治疗效果有限
  • 外周神经损伤后，神经微环境发生剧烈变化——细胞浸润、增殖、通讯网络重构
  • 传统观点聚焦于神经元和施万细胞，但 非神经细胞（成纤维细胞、免疫细胞、血管细胞）在疼痛发生和维持中的作用被严重低估

研究空白

  • 缺乏对外周神经不同解剖分区（神经外膜/束膜/内膜）细胞异质性的系统理解
  • 细胞间配体-受体通讯网络在损伤后的动态变化尚未明确
  • 谁在"发信号"（配体来源细胞）？谁在"接收信号"（受体表达细胞）？
核心问题：坐骨神经在正常和慢性压迫损伤（CCI）后，其细胞组成如何变化？不同细胞类型之间通过哪些配体-受体相互作用进行通讯，从而驱动神经病理性疼痛？

研究策略

  • 建立大鼠CCI模型（慢性压迫损伤），采集Naive、3天、12天、60天四个时间点的坐骨神经
  • 利用 10X Genomics 单细胞转录组测序，鉴定所有细胞类型及其亚群
  • 通过 SingleCellSignalR 挖掘配体-受体相互作用网络

2. 技术路线

CCI模型建立 → 10X Genomics scRNA-seq → Seurat v3 聚类与注释 → Harmony 批次校正 → SingleCellSignalR LR分析 → RNAscope 空间验证

实验样本设计

  • 模型：Sprague Dawley大鼠，CCI手术（4根铬肠线结扎坐骨神经，1mm间距）vs 正常对照
  • 时间点：未受损（Naive） + 损伤后第3天、12天、60天
  • 测序技术：10X Genomics Chromium Single Cell 3' Kit v2（基于微流控油包水液滴技术）
  • 组织准备：心脏灌注PBS → 坐骨神经解剖 → 酶消化 → 40μm滤网过滤
  • 空间验证：RNAscope 原位杂交技术验证关键标记物在组织切片中的真实空间分布

数据分析流程

  • 比对：CellRanger v3.0.0 → 大鼠基因组（Rn6）
  • 质控：保留200-5500基因且线粒体比例<10%的细胞
  • 标准化：sctransform（正则化负二项回归）
  • 批次校正：Harmony（整合不同时间点和生物学重复）
  • 聚类：30个主成分，分辨率0.8，Leiden聚类
  • 细胞注释：基于已知标志基因的差异表达分析

4. 施万细胞亚型——外周神经的驻留神经胶质细胞

施万细胞（Schwann cells）是坐骨神经微环境中的驻留神经胶质细胞，在正常稳态和损伤响应中发挥核心作用。本研究鉴定出4种功能不同的施万细胞亚型：

施万细胞亚型特征标志基因正常占比损伤后变化
有髓施万细胞 (Myelinating) 包裹大直径轴突，形成髓磷脂鞘 Mbp, Plp1, Mpz, Prx 58.4% 损伤后去分化，转变为修复表型
Remak施万细胞 (Remak) 包裹小直径轴突（Remak束），无髓 Cdh2, Ngfr 36.1% 同样参与修复响应
修复型施万细胞 (Repair) 损伤后特异性涌现，高表达Ngfr，分泌神经营养因子，清理碎片 Ngfr (p75NTR)高表达 几乎无（仅1个细胞） 3天18% → 12天26% → 60天回归
分裂期施万细胞 (Dividing) 损伤高峰期进入细胞周期进行增殖 Mki67, Ccnb1 极少 损伤高峰期大量出现
核心发现：正常神经中~94%的施万细胞处于高度特化的有髓/Remak状态。损伤后诱导产生修复型施万细胞（标志物Ngfr/p75NTR），其在3-12天爆发式增长后于60天基本回归基线，提示其为损伤特异性的一过性表型转化。

→ 修复型施万细胞是损伤后SC表型可塑性的核心体现，其标志物为神经病理性疼痛提供了潜在生物标志物。

5. 关键技术原理与单细胞测序方法

5.1 10X Genomics Chromium 单细胞测序原理

  • 核心原理：利用微流控芯片将单个细胞与携带独特条形码（Barcode）的凝胶微珠（GEM）包裹在油包水微滴中。每个液滴作为一个独立的"微型反应器"，在液滴内完成细胞裂解、mRNA捕获和逆转录。
  • 分子标签策略：每个微珠携带大量相同的细胞条形码和独特的分子标识符（UMI），使得测序后能追溯每个转录本来自哪个细胞、哪个原始mRNA分子。
  • 为什么没测出神经元？坐骨神经中只有轴突缺乏细胞核——轴突mRNA总量极低，标准10X单细胞测序只能捕获有核细胞。神经元胞体位于背根神经节（DRG）中。

5.2 scTransform 标准化原理

  • 使用正则化负二项回归模型对UMI计数进行建模，直接校正测序深度和基因长度的系统性偏差，保留生物学变异。
  • 比传统LogNormalize方法更有效地消除测序深度带来的影响。

5.3 Harmony 批次校正原理

  • 通过"软聚类（Soft k-means）→ 计算数据集特异性偏移 → 线性校正 → 迭代收敛"的流程，消除不同时间点之间的技术偏差。
  • 校正后细胞按其生物学本质（基因表达谱）而非实验来源聚类。
整体分析框架："10X Genomics单细胞测序"（捕获有核细胞转录组）→ "Seurat v3 + Harmony"（质控、标准化、批次校正、聚类）→ "SingleCellSignalR"（配体-受体通讯预测）→ "RNAscope"（空间验证）。

6. 细胞间通讯分析工具：SingleCellSignalR

6.1 工具概述

  • 软件包：SingleCellSignalR（R语言，v1.0）
  • 开发者：Cabello-Aguilar et al., 2020, Nucleic Acids Research（PMID: 32246835）
  • GitHub：https://github.com/SCA-IRCM/SingleCellSignalR

6.2 基本原理——配体-受体（LR）共表达分析

  • 核心逻辑：基于"配体-受体共表达"原理——如果细胞A表达配体L，细胞B表达受体R，则推测A和B之间可能存在通过该L-R对的旁分泌通讯。
  • 配体-受体数据库来源：利用SingleCellSignalR框架内设定的一系列经过人工筛选与整理的公共数据库集（a set of curated databases），共包含3251对已知配体-受体对，涵盖生长因子、细胞因子、趋化因子、细胞外基质成分等多种信号分子。
  • LR Score计算：对于每对预测的L-R相互作用，计算一个相互作用评分（LR score），评分越高表示该通讯通路的可靠性越高。本研究中使用的阈值：正常神经LR > 0.05，损伤后LR > 0.5。
  • 输入：已经注释好的Seurat对象（包含细胞类型标签的标准化表达矩阵）。
  • 输出：细胞类型之间的配体-受体相互作用矩阵、弦图（Circos plot）、热图等可视化结果。
SingleCellSignalR的核心特点：提供了从单细胞数据直接推断细胞间通讯的一站式解决方案，内置LR数据库和评分系统。其基本原理是"配体-受体共表达"，即通过配体细胞和受体细胞之间的表达匹配来推断可能的细胞间通讯。

→ Cntf-Cntfr通路：这是一个在正常稳态中即存在的通迅通路，揭示施万细胞与成纤维细胞之间的"分子对话"维持着神经束膜的完整性。

  • 损伤痛觉触发通路：损伤激活后，细胞间通讯网络彻底重构。分析表明，修复型施万细胞表面的神经生长因子受体（Ngfr/p75NTR）被强烈激活，其配体直接来源于成纤维细胞高分泌的神经生长因子（Ngf），这揭示了成纤维细胞可能是触发和维持损伤后外周神经病理性疼痛的药理学核心干预靶点
  • 第二关键通路：成纤维细胞分泌的多效生长因子（Ptn）与修复型施万细胞表面的受体蛋白酪氨酸磷酸酶ζ1（Ptprz1）之间的相互作用，参与损伤后施万细胞的增殖与分化调控
  • 网络重构程度：损伤诱导的LR互作网络较正常状态显著扩大，成纤维细胞成为通讯网络的"枢纽"，连接多种细胞类型
→ 核心结论：损伤使细胞间通讯网络从稳态维持模式转变为痛觉信号驱动模式，成纤维细胞（Fibroblasts）处于该转变的枢纽位置。成纤维细胞→修复型施万细胞的Ngf→Ngfr通路是关键痛觉触发通路。

7. 有没有神经细胞相关的细胞间通讯？

施万细胞——既是通讯的发送者也是接收者

在本研究中，施万细胞（Schwann cells）作为唯一的驻留神经胶质细胞，在配体-受体通讯网络中同时扮演发送者和接收者角色：

通讯角色配体/受体通讯伙伴生理意义
发送者（配体输出） 有髓施万细胞 → 分泌Cntf → 束膜成纤维细胞（Cntfr受体） 稳态维持，束膜完整性调控（LR score = 0.84）
接收者（受体输入） 修复型施万细胞 ← Ngfr (p75NTR) ← 内膜成纤维细胞分泌Ngf 损伤后疼痛信号放大
接收者（受体输入） 修复型施万细胞 ← Ptprz1 ← 成纤维细胞分泌Ptn 损伤后细胞增殖与分化调控
发送者与接收者 Timp3-Kdr通路 成纤维细胞Timp3 → 血管细胞Kdr (VEGFR2) 损伤诱导的血管新生调控
关键发现：施万细胞与成纤维细胞之间的双向通讯是神经微环境稳态和损伤后疼痛的核心驱动力。特别是成纤维细胞→修复型施万细胞（Ngf→Ngfr）通路，揭示了一个此前未被充分认识的上游调控机制——成纤维细胞很可能是触发和维持损伤后外周神经病理性疼痛的药理学核心干预靶点。

8. 结论与展望

核心发现

  • 首次在单细胞分辨率下系统描绘了大鼠坐骨神经在CCI损伤后4个时间点的细胞图谱，鉴定出 32个细胞亚群
  • 施万细胞（PNS驻留的神经胶质细胞）在损伤后表现出高度可塑性：有髓→修复型去分化、分裂增殖、一过性修复型爆发
  • 成纤维细胞是异质性最高的细胞群体（≥9个正常亚型 + 损伤特异性亚型），在通讯网络中处于枢纽位置
  • SingleCellSignalR分析揭示：正常中有Cntf→Cntfr（稳态维持），损伤后有Ngf→Ngfr和Ptn→Ptprz1（痛觉触发）

临床转化潜力

  • 为开发靶向成纤维细胞-施万细胞通讯的镇痛药物提供了分子基础
  • 修复型施万细胞的标志物（Cyp2u1、Lpar3）可作为神经病理性疼痛的潜在生物标志物
