# Marker 提取工作簿

本目录保留当前流程使用的正式工作簿：

- `our_markers.xlsx`：正式 Marker 总表；
- `our_markers_by_cell.xlsx`：按细胞类型整理的查看与交付视图；
- `our_marker_papers.xlsx`：44 条 Marker 文章任务主清单；
- `our_paper_metadata.xlsx`：文章组织、神经细胞和统计方法等支持性元数据。

论文 PDF 在 `../pdf/`，导师参考工作簿在 `../reference/`。Gemini 的提取结果必须经 Codex 对照原始材料复查后，才能写入正式总表。
