# 单细胞RNA测序数据分析 —— 完成报告

## 数据概况

| 项目 | 详情 |
|---|---|
| **文献** | Peripheral Nerve Single-Cell Analysis (eNeuro, 2020) |
| **GEO编号** | GSE147285 |
| **数据类型** | Drop-seq DGE 矩阵 |
| **样本数** | 4 个（损伤3天、新生FACS、新生磁珠、未损伤） |
| **总细胞数** | 13,200 → 质控后 **12,236** |
| **总基因数** | 22,716 → 过滤后 19,092 |

## 分析流程执行结果

| 步骤 | 状态 | 结果 |
|---|---|---|
| 1. 数据下载 | ✅ | 4 个样本全部下载（共 ~16.6 MB） |
| 2. 数据读取合并 | ✅ | 13,200 细胞 × 22,716 基因 |
| 3. 质控过滤 | ✅ | 去除 964 个低质量细胞 → 12,236 |
| 4-6. 标准化+PCA | ✅ | 2,000 高变基因，30 个主成分 |
| 7. 批次校正 | ✅ | Harmony（10次迭代） |
| 8-9. 聚类+UMAP | ✅ | Leiden 聚类 → **18 个 cluster** |
| 10. 细胞注释 | ✅ | 标注 **7 种细胞类型** |
| 11. 结果保存 | ✅ | h5ad + CSV + 9张图 |
