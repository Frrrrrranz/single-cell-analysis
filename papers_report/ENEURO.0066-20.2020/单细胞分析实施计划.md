# 单细胞RNA测序数据分析 — 细胞注释分类

## 背景

文献 *"Peripheral Nerve Single-Cell Analysis Identifies Mesenchymal Ligands that Promote Axonal Growth"* (eNeuro, 2020) 使用 Drop-seq 技术对小鼠坐骨神经进行了单细胞RNA测序。数据存储在 **GEO: GSE147285**。

## 数据概览

| 样本 | GEO编号 | 文件名 | 描述 |
|---|---|---|---|
| 损伤3天 | GSM4423506 | `Inj_Sciatic_3d.txt.gz` | 损伤后3天坐骨神经 |
| 新生FACS | GSM4423507 | `Neo_Sciatic_FACS.txt.gz` | 新生鼠坐骨神经（FACS分选） |
| 新生磁珠 | GSM4423508 | `Neo_Sciatic_Beads.txt.gz` | 新生鼠坐骨神经（磁珠去髓磷脂） |
| 未损伤 | GSM4423509 | `Uninj_Sciatic.txt.gz` | 未损伤坐骨神经 |

数据格式为 Drop-seq DGE 矩阵（基因 × 细胞的文本文件）。

## 目标

对文献的单细胞数据进行标准分析流程，最终实现**细胞类型注释分类**，复现文献中鉴定的细胞类型：
- 施万细胞（Schwann cells）
- 间充质细胞（Mesenchymal cells）  
- 巨噬细胞（Macrophages）
- 内皮细胞（Endothelial cells）
- 周细胞/平滑肌（Pericytes/VSM）
- 淋巴细胞
- 肥大细胞
- B细胞 等

## 技术方案

使用 **Python + Scanpy** 进行分析（Scanpy 是 Python 生态中最主流的单细胞分析工具）。

### 分析流程

```
1. 数据下载 → 2. 数据读取与预处理 → 3. 质控过滤 → 4. 标准化 → 5. 高变基因选择
→ 6. PCA降维 → 7. 邻域图构建 → 8. Leiden聚类 → 9. UMAP可视化
→ 10. 细胞类型注释（基于标志基因）→ 11. 结果可视化与导出
```

### 标志基因参考（来自文献）

| 细胞类型 | 标志基因 |
|---|---|
| 施万细胞 | Sox10, Ngfr, S100b, Mbp, Plp1 |
| 间充质细胞 | Pdgfra, Sox9, Dpt, Etv1 |
| 巨噬细胞 | Aif1, Cd68 |
| 内皮细胞 | Pecam1 (Cd31) |
| 周细胞/平滑肌 | Desmin, Acta2 |
| 淋巴细胞 | Ptprcap, Trbc2 |
| B细胞 | Cd19 |
| 肥大细胞 | Cpa3 |
