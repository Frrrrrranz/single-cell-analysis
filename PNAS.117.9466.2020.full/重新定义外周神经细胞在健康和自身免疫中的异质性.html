重新定义外周神经细胞
在健康和自身免疫中的异质性

Redefining the heterogeneity of peripheral nerve cells in health and autoimmunity

PNAS, 2020 · Wolbert et al.

关键词：单细胞RNA测序 · 外周神经系统 · 施万细胞标志物 · 自身免疫性神经炎 · CellPhoneDB细胞间通讯

1. 研究背景

外周神经系统（PNS）细胞组成的传统认知与局限

  • 传统观点认为PNS细胞组成简单：主要是施万细胞（有髓/无髓）和轴突
  • 成纤维细胞等其他细胞类型的功能和谱系归属长期存在争议，缺乏可靠的分子标志物
  • 缺乏对健康小鼠PNS的"公正"（unbiased）单细胞转录组学表征

自身免疫性神经炎中细胞互作机制的空白

  • 格林-巴利综合征（GBS）和CIDP等自身免疫性神经炎中，免疫细胞如何与PNS驻留细胞相互作用尚不明确
  • 自身免疫反应中PNS实质细胞如何响应？细胞间互作网络如何变化？
核心问题：健康PNS中有哪些细胞类型？它们的分子标记物是什么？在自身免疫性神经炎中，细胞间通讯网络如何重构？

研究策略

  • 对健康小鼠PNS（臂丛+坐骨神经）进行 10X Genomics 单细胞测序，无偏鉴定所有细胞类型
  • 提供新型细胞标志物（如Apod、Sfrp4）用于细胞区分
  • 在ICAM-1-/-NOD小鼠（慢性自身免疫性神经炎模型）中研究细胞互作网络的变化
  • 使用 CellPhoneDB 预测细胞间通讯网络

2. 技术路线

PNS组织采集 → 酶消化+髓鞘磁珠+流式分选 → 10X Genomics scRNA-seq → Seurat v3 聚类注释 → CellPhoneDB LR互作预测 → 免疫组化/RNAscope验证

实验样本设计

  • 健康组：C57BL/6J小鼠臂丛神经+坐骨神经（灌注PBS后解剖）
  • 疾病组：ICAM-1-/-NOD小鼠——自发性慢性炎性脱髓鞘性多发性神经根神经病（CIDP）模型
  • 细胞提取优化：酶消化 → 抗髓磷脂磁珠去除髓鞘碎片 → 流式分选（Zombie NIR + Calcein-AM + DAPI三重活细胞标记）
  • 测序：10X Genomics Chromium 3' Kit v2，每样本混合12只小鼠细胞，3个生物学重复

数据分析流程

  • 比对：CellRanger v3.0.2 → 小鼠基因组mm10
  • 标准化：正则化负二项回归（与scTransform类似）
  • 降维与聚类：UMAP + Seurat v3.0.0（30个主成分）
  • 差异表达：FindMarkers（Wilcoxon秩和检验，阈值0.25 logFC）
  • 批次校正：Harmony（用于疾病组vs对照组比较）
  • 通讯预测：CellPhoneDB（小鼠基因ID→人类同源基因转换后分析）

→ 关键结论：Apod是nmSCs的高特异性标志物，Sfrp4是神经成纤维细胞的特异性标志物，均经RNAscope空间验证。

  • 无髓施万细胞（nmSCs）：在外周神经中长期缺乏特异性分子标记物。本研究通过scRNA-seq鉴定出Apod（载脂蛋白D）在nmSCs中高度特异性表达——RNAscope验证其在坐骨神经横切面中与Sox10共定位，且分布于小直径轴突周围，符合nmSCs的解剖位置
  • 成纤维细胞（Fibroblasts）：传统上仅以形态学（梭形、纺锤状）区分，缺乏特异性分子标记。本研究鉴定出Sfrp4（分泌型卷曲相关蛋白4）在神经成纤维细胞中特异性表达——RNAscope证实Sfrp4+细胞主要分布在神经外膜，与Sox10+施万细胞不重叠
  • 独立验证：使用hGFAP-GFP和PDGFRα-EGFP转基因小鼠进行独立免疫组化验证，确认标志物的可靠性
  • 人类PNS保守性：人腓肠神经活检标本免疫组化确认SOX10、MBP、CD34、SMA等标志物在人与小鼠间的保守性
→ 研究意义：Apod和Sfrp4为外周神经组织学病理诊断提供了全新的分子工具。

特征MC（髓系细胞）MP（巨噬细胞）

与CNS小胶质细胞的关键差异

  • PNS巨噬细胞不表达CNS小胶质细胞的特异性标志物：P2ry12, Tmem119, Sparc, Olfm3
  • PNS巨噬细胞表达Aif1/Iba1（与小胶质细胞共享），但转录组整体差异显著
  • PNS巨噬细胞具有混合起源（卵黄囊+造血干细胞），而CNS小胶质细胞几乎全部来源于卵黄囊前体
核心发现：PNS驻留巨噬细胞在转录组上显著不同于CNS小胶质细胞，具有独特的分子特征、解剖分布和谱系起源。这对理解PNS特异性免疫疾病（如格林-巴利综合征）有重要意义。

5. 关键技术原理与单细胞测序方法

5.1 10X Genomics Chromium 单细胞测序原理

  • 核心原理：微流控芯片将单个细胞与携带独特条形码（Barcode）的凝胶微珠包裹在油包水微滴（GEM）中。每个液滴作为一个独立的"微型反应器"，完成细胞裂解、mRNA捕获和逆转录。
  • 分子标签策略：每个微珠携带大量相同的细胞条形码和独特的分子标识符（UMI）。测序后通过条形码区分每个细胞的数据。
  • 本研究使用流式分选（而非普通10X流程）——通过Zombie NIR + Calcein-AM + DAPI三重染色，确保只捕获高质量活细胞，去除髓鞘碎片和死细胞。

5.2 本研究的实验技术创新点

  • 髓鞘去除优化：使用抗髓磷脂磁珠（Myelin Removal Beads）去除富含脂质的髓鞘碎片——这是外周神经组织特有的技术挑战，因为髓磷脂会干扰微流控捕获和测序质量。
  • 多重验证：scRNA-seq筛选候选标志物 → RNAscope空间验证 → 免疫组化确认蛋白表达 → 转基因小鼠独立验证。
  • 跨物种保守性验证：使用人腓肠神经活检标本确认主要细胞类型的标志物在人与小鼠之间的保守性。
整体分析框架："PNS组织采集+酶消化+髓鞘去除+流式分选"（优化细胞提取）→ "10X Genomics scRNA-seq"（单细胞转录组）→ "Seurat v3 + Harmony"（聚类+批次校正）→ "CellPhoneDB"（LR通讯预测）→ "RNAscope/免疫组化"（空间与蛋白层面验证）。

6. 细胞间通讯分析工具：CellPhoneDB

6.1 工具概述

  • 软件包：CellPhoneDB（Python / 命令行工具）
  • 开发者：Wellcome Sanger Institute（Ventura-Traveset Lab）
  • 官方论文：Efremova et al., 2020, Nature Protocols; Vento-Tormo et al., 2018, Nature
  • 官方网站：https://www.cellphonedb.org/

6.2 基本原理——配体-受体（LR）共表达的统计检验

  • 核心逻辑：基于"配体-受体共表达"原理——如果细胞类型A表达配体L，细胞类型B表达受体R，则推测A和B之间可能存在通过该L-R对的旁分泌通讯。
  • 计算流程：
    1. 将单细胞数据中的细胞按细胞类型分组
    2. 对于每个配体-受体对，计算两种细胞类型中配体和受体的平均表达水平
    3. 通过随机置换检验（Permutation test）评估该LR对的表达是否显著高于随机预期（p值）
    4. 输出所有显著LR对的列表以及细胞类型之间的互作网络
  • 配体-受体数据库来源：CellPhoneDB自带经过专家整理和人工筛选的配体-受体数据库，涵盖人类已知的配体-受体对，特别支持多亚基受体复合物（如TGF-β受体、细胞因子受体等）的匹配。
  • 本研究的适配处理：因CellPhoneDB原始数据库基于人类，本研究将小鼠基因ID通过biomaRt转换为人类同源基因后进行分析

6.3 与SingleCellSignalR的主要区别

  • CellPhoneDB使用统计检验（置换检验）评估LR相互作用显著性；SingleCellSignalR使用LR score评分
  • CellPhoneDB特别支持多亚基复合物（配体和受体可由多个基因组成），更适用于免疫信号通路分析
CellPhoneDB的核心特点：使用严格的统计学检验（置换检验），特别适合分析多亚基受体复合物参与的细胞间通讯，如免疫突触信号。内置的LR数据库经过了专家人工筛选和整理。

→ 关键结论：自身免疫神经炎中成纤维细胞和血管平滑肌/周细胞的通讯连接数量跃升，成为局部网络的核心枢纽。

  • 分析工具与原理：采用CellPhoneDB（基于Python）生物信息学框架，基于"配体-受体共表达"基本原理，使用内置的经过专家整理的配体-受体数据库，通过置换检验计算相互作用显著性
  • 疾病模型背景：ICAM-1-/-NOD小鼠——一种自发性CIDP样模型，表现为T细胞和B细胞在PNS中的大量浸润
  • 细胞比例变化：患病神经中T细胞和B细胞显著增加，施万细胞、成纤维细胞和血管细胞的比例相对下降
  • 网络重构核心发现：健康PNS中，有髓施万细胞（mySCs）的互作连接性较低；但在自身免疫神经炎中，成纤维细胞（Fibro）和血管平滑肌/周细胞（vSMC/PC）获得了更多的通讯连接控制权
→ 核心结论：自身免疫性神经炎不仅仅是免疫细胞的浸润，更是整个PNS细胞间通讯网络的系统性重构。成纤维细胞和血管细胞在疾病中成为通讯网络的"枢纽"。

7. 有没有神经细胞相关的细胞间通讯？

施万细胞——自身免疫炎症中的响应者

施万细胞（Schwann cells）作为PNS的唯一驻留神经胶质细胞，在本研究的自身免疫神经炎中表现出显著的转录组响应和通讯网络变化：

细胞类型在健康PNS中的状态在自身免疫神经炎中的变化
有髓施万细胞 (mySCs) 稳定的髓鞘维持状态，通讯连接性较低 被浸润淋巴细胞"攻击"，上调抗原呈递分子（H2-K1, H2-D1, B2m）、免疫蛋白酶体亚基（Psmb8, Psmb10）以及与创伤后施万细胞分化和神经再生相关的 Sostdc1 和 Zeb2——表明其主动参与免疫应答
无髓施万细胞 (nmSCs) 表达Ngfr，包裹小直径轴突（Remak束），与轴突维持相关 同样参与炎症响应，与浸润T细胞、B细胞产生新的配体-受体相互作用
成纤维细胞 (Fibro) 维持细胞外基质稳态，与施万细胞有中等程度的通讯 获得通讯网络控制权——在疾病中通讯连接数量跃升，成为细胞间互作网络的"枢纽"
血管平滑肌/周细胞 (vSMC/PC) 血管支持和血-神经屏障维持，通讯有限 通讯连接显著增加，与免疫细胞（T细胞、B细胞和髓系细胞）的互作增强
关键发现：自身免疫性神经炎中，虽然施万细胞（神经胶质细胞）自身也参与了免疫应答，但通讯网络的核心枢纽并不是施万细胞，而是成纤维细胞和血管平滑肌/周细胞。

PNS与CNS的保守免疫响应模块

  • 本研究将PNS自身免疫数据与已发表的EAE（CNS自身免疫模型）数据进行交叉比较
  • 发现PNS和CNS的胶质细胞共享部分保守的免疫响应模块
  • 提示外周和中枢神经系统存在通用的胶质细胞免疫响应机制

8. 结论与展望

核心贡献

  • 首次在单细胞水平系统描绘了健康PNS的细胞组成——鉴定出12种细胞类型/亚型
  • 鉴定出无髓施万细胞（nmSCs）的新型标志物Apod和神经成纤维细胞的标志物Sfrp4
  • 明确区分髓系细胞簇（MC, Cx3cr1+）与巨噬细胞簇（MP, Cxcl4/Pf4+）——在转录组上显著不同于CNS小胶质细胞
  • 在自身免疫神经炎中，CellPhoneDB分析揭示——PNS细胞间通讯网络系统性重构，成纤维细胞和血管细胞获得通讯网络控制权

临床意义

  • Apod和Sfrp4为PNS病理诊断提供分子工具，可用于区分外周神经肿瘤中细胞起源
  • PNS驻留巨噬细胞作为潜在的免疫治疗靶点——因其与CNS小胶质细胞的不同可能允许PNS特异性靶向
  • 成纤维细胞在自身免疫炎症中的核心枢纽地位提示其可能是CIDP等疾病的潜在治疗靶点
