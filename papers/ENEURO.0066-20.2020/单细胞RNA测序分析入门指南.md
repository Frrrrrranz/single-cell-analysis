## 一、什么是单细胞RNA测序（scRNA-seq）数据？

### 1.1 传统测序 vs 单细胞测序

想象你有一杯混合果汁（草莓+芒果+蓝莓）：

| | 传统 bulk RNA-seq | 单细胞 scRNA-seq |
|---|---|---|
| **类比** | 把整杯果汁搅匀后分析成分 | 把每颗水果单独分析 |
| **结果** | 得到"平均"基因表达 | 得到**每个细胞**各自的基因表达 |
| **能做什么** | 知道整个组织表达了哪些基因 | 知道组织里有哪些**细胞类型**，每种细胞表达什么基因 |

### 1.2 本文用了什么技术？

本文使用 **Drop-seq**（液滴法单细胞测序）：
1. 把坐骨神经组织消化成单个细胞悬液
2. 用微流控芯片把每个细胞包裹在一个油滴里（每个油滴 = 一个微型实验室）
3. 每个油滴里有一个带有**独特条形码**的微珠，能捕获该细胞的所有 mRNA
4. 最后统一测序，通过条形码区分每个细胞的数据

### 1.3 数据长什么样？

最终得到的核心数据是一个**数字基因表达矩阵（DGE Matrix）**：

```
              Cell_1  Cell_2  Cell_3  Cell_4  ...
Gene_Sox10      5       0       0       3     ...
Gene_Pdgfra     0       8       7       0     ...
Gene_Aif1       0       0       0       0     ...
Gene_Pecam1     0       0       0       6     ...
...
```

- **行** = 基因（约 20,000+ 个）
- **列** = 细胞（本文约几千个）
- **值** = UMI 计数（该细胞中该基因被检测到的 mRNA 分子数）
- 大部分值是 **0**（因为单个细胞中大多数基因不表达，这叫"稀疏矩阵"）

## 二、数据存在哪里？怎么下载？

### 2.1 GEO 数据库 —— 生物数据的"GitHub"

几乎所有发表的测序数据都必须上传到公共数据库，其中最主要的是：

> **GEO**（Gene Expression Omnibus）—— NCBI 旗下的基因表达数据库
> 网址：https://www.ncbi.nlm.nih.gov/geo/

每个数据集有一个唯一编号，格式为 **GSE + 数字**，比如本文的数据：

> **GSE147285** → https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE147285

| GEO 样本号 | 文件名 | 描述 |
|---|---|---|

### 2.3 下载方式

GEO 提供两种下载方式：
- **HTTP 直接下载**：点击链接就能下载 `.txt.gz` 文件（压缩的文本文件）
- **FTP 下载**：通过 FTP 客户端批量下载

我们的分析脚本会用 Python 自动帮你下载，你不需要手动操作。

### 2.4 其他常见的数据存储位置

## 三、用 R 还是 Python 分析？

### 3.1 两大阵营

单细胞分析领域有两大主流工具：

| | **R + Seurat** | **Python + Scanpy** |
|---|---|---|
| **开发者** | Satija Lab（纽约大学） | Theis Lab（慕尼黑） |
| **历史** | 更早，用户群更大 | 较新，发展迅速 |
| **文献引用** | 目前更多论文使用 | 逐渐增多 |
| **可视化** | ggplot2 生态，图更美 | matplotlib/seaborn |
| **大数据处理** | 内存占用较高 | 更高效（基于 anndata） |
| **学习曲线** | 需要 R 基础 | 需要 Python 基础 |

### 3.2 本次分析的选择

> [!TIP]
> 我们使用 **Python + Scanpy**，原因：
> 1. 你已经有 Python 环境，不需要额外安装 R
> 2. Scanpy 的 API 设计更直观，一行代码做一件事
> 3. 对于你的任务（下载数据 → 聚类 → 注释），Python 完全够用
> 4. 结果和用 R/Seurat 分析是等价的，没有对错之分

### 3.3 实际上论文用了什么？

本文使用的是 **R + Seurat**（加上 Harmony 做批次校正）。但这不影响我们用 Python 复现——底层数学算法是一样的（PCA、UMAP、Leiden聚类等都是通用算法）。

## 四、分析流程详解（最核心的部分）

整个分析可以分为 **6 大步骤**，每一步都有明确的目的：

```
📥 下载数据
   ↓
🔍 质控过滤（去掉坏细胞）
   ↓
📊 标准化（让细胞间可比）
   ↓
🧮 降维（20000个基因 → 几十个主成分 → 2D图）
   ↓
🎯 聚类（把相似的细胞分到一组）
   ↓
🏷️ 注释（根据标志基因判断每组是什么细胞）  ← 你的老师要求的核心目标
```

### 步骤 1：质控过滤 —— 去掉"坏"细胞

不是所有捕获的液滴都包含健康的细胞，需要过滤掉：

| 过滤条件 | 去掉什么 | 为什么 |
|---|---|---|
| 基因数太少（<200） | 空液滴 / 碎片 | 真正的细胞至少应该表达几百个基因 |
| 基因数太多（>5000） | 双细胞（一个液滴包了两个细胞） | 异常高的基因数说明不是单个细胞 |
| 线粒体基因比例高（>10%） | 死亡/破损细胞 | 细胞破损时细胞质mRNA流失，但线粒体mRNA因膜保护而残留 |

### 步骤 2：标准化 —— 让细胞间可比

每个细胞的测序深度不同（有的测到5000条mRNA，有的只有500条），直接比较不公平。标准化就是把所有细胞调整到相同的"尺度"上。

```python
# 常见做法：
# 1. 每个细胞的总 UMI 数归一化到 10,000
# 2. 取对数（log1p），压缩数值范围
```

### 步骤 3：高变基因选择

20,000+ 个基因中，大部分在所有细胞中表达差不多（比如管家基因），对区分细胞类型没有帮助。只选择**变化最大的基因**（通常 2000-3000 个）用于后续分析，这些基因才是区分不同细胞的"关键特征"。

### 步骤 4：降维

2000 个基因维度仍然太高，无法可视化。降维分两步：

1. **PCA**（主成分分析）：2000维 → 20-50维（保留主要信息，去除噪声）
2. **UMAP**（统一流形逼近）：20维 → **2维**（用于画图，让人眼可以看到聚类结构）

> UMAP 图就是你在论文里看到的那种**彩色散点图**，每个点是一个细胞，相似的细胞靠在一起。

### 步骤 5：聚类 —— 自动分组

使用 **Leiden 算法**（或 Louvain 算法）在 PCA 空间中把相似的细胞自动分成若干组（cluster）。算法不知道这些组是什么细胞，只知道它们基因表达相似。

输出结果：每个细胞被打上一个数字标签（Cluster 0, 1, 2, 3, ...）

### 步骤 6：细胞注释 —— 你老师要求的核心 ⭐

这是**最关键也最需要生物学知识**的一步。我们需要根据每个 cluster 高表达的基因来判断它是什么细胞类型。

方法是：检查文献中提到的**标志基因**（marker genes）在每个 cluster 中的表达情况：

| 如果某个 cluster 高表达... | 那它可能是... |
|---|---|
| Sox10, S100b, Mbp | **施万细胞**（Schwann cells） |
| Pdgfra, Sox9, Dpt | **间充质细胞**（Mesenchymal cells） |
| Aif1 (Iba1), Cd68 | **巨噬细胞**（Macrophages） |
| Pecam1 (Cd31) | **内皮细胞**（Endothelial cells） |
| Acta2, Desmin | **周细胞/平滑肌**（Pericytes/VSM） |
| Ptprcap, Trbc2 | **淋巴细胞**（Lymphocytes） |

## 五、最终你会得到什么？

运行完分析脚本后，你会得到以下结果：

1. **UMAP 聚类图** —— 每个点是一个细胞，颜色代表自动分组
2. **UMAP 注释图** —— 颜色代表你判断出的细胞类型名称（施万细胞、间充质细胞等）
3. **标志基因点图/小提琴图** —— 展示标志基因在各个 cluster 中的表达情况，证明你的注释是合理的
4. **细胞比例统计** —— 每种细胞类型占多少比例

这些图就是你向老师展示"我做到了细胞注释分类"的核心证据。
